# 项目开发规则

## 代码结构规范

### 关注点分离（Separation of Concerns）
项目必须遵循 **HTML (结构)**、**CSS (表现)**、**JavaScript (行为)** 三分离原则。

1.  **HTML**: 仅包含页面结构和语义化标签，不得包含内联样式（style="..."）和内联脚本（onclick="..."）。
2.  **CSS**: 所有样式定义必须放置在独立的 `.css` 文件中，通过 `<link>` 标签引入。
3.  **JavaScript**: 所有业务逻辑和交互代码必须放置在独立的 `.js` 文件中，通过 `<script src="...">` 引入。

### 目录结构约定
- `webview/dist/index.html`: 入口文件
- `webview/dist/css/`: 存放样式文件 (`index.css`, `base.css` 等)
- `webview/dist/js/`: 存放脚本文件 (`index.js`, `utils.js` 等)
- `webview/dist/js/api/`: 存放明道云 API 组件 (`MingdaoArray.js` 等)

## 编码规范
- 使用语义化的类名和变量名。
- 保持代码整洁，适当添加注释。

## 静态资源版本策略（Cache Busting）
- 所有通过 `<link>` 引入的 CSS 与通过 `<script>` 引入的 JS 必须追加版本查询参数，例如：`?v=1.0.5` 或 `?v=20260108`。
- 每次修改对应的 CSS/JS 文件后，必须同步更新版本号，确保浏览器缓存失效并刷新最新样式与脚本。
- 建议版本号格式：
  - 语义化版本：如 `1.0.5`（适合正式发布与变更记录）
  - 时间戳版本：如 `20260108` 或 `202601081230`（适合快速迭代与联调）
- 示例（入口 HTML 必须遵循）：
  - `<link rel="stylesheet" href="./css/base.css?v=1.0.5">`
  - `<link rel="stylesheet" href="./css/index.css?v=1.0.5">`
  - `<script src="./js/index.js?v=1.0.5"></script>`
- 图片等静态资源如有强缓存需求，优先采用文件名指纹（hash）或追加版本参数的方式控制缓存（例如：`./assets/img/logo.png?v=1.0.5`）。
- 禁止使用内联样式与内联脚本；版本策略只适用于外链资源（符合三分离原则）。
