# 陪诊助手 - 纯HTML版本

这是一个完全使用原生HTML、CSS和JavaScript构建的陪诊小程序，无需React或其他框架依赖。

## 功能特性

### ✨ 核心功能
- **AI智能助手**：提供陪诊相关问题的智能问答
- **患者管理**：添加、查看和管理患者信息
- **陪诊流程**：完整的就诊记录和报告生成
- **备忘录系统**：管理提醒和待办事项
- **新手引导**：首次使用时的功能介绍

### 📱 技术特点
- 纯原生技术栈（HTML + CSS + JavaScript）
- 移动优先的响应式设计
- 本地存储（localStorage）数据持久化
- 无需构建工具，直接在浏览器中运行

## 快速开始

### 方式一：直接打开
1. 下载所有文件到本地文件夹
2. 双击 `index.html` 文件
3. 在浏览器中直接使用

### 方式二：使用本地服务器（推荐）
```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Python 2
python -m SimpleHTTPServer 8000

# 或使用 Node.js
npx http-server
```

然后访问 `http://localhost:8000`

## 主要页面

### 1. 智能体页面
- AI聊天对话
- 快捷问题按钮
- 智能回答陪诊相关问题

### 2. 患者库
- 患者列表展示
- 添加新患者
- 查看患者详情

### 3. 备忘录
- 查看即将到来的提醒
- 添加新提醒

### 4. 设置
- 查看新手引导
- 导出数据

## 数据存储

所有数据使用浏览器的 localStorage 存储，包括：
- 患者信息
- 陪诊记录
- 提醒事项
- 聊天记录

**注意**：清除浏览器数据会导致所有信息丢失，建议定期使用"导出数据"功能备份。

## 开发说明

### 修改样式
编辑 `styles.css` 文件，使用CSS变量可以快速调整配色：

```css
:root {
    --primary-color: #3b82f6;  /* 主色调 */
    --bg-color: #f9fafb;        /* 背景色 */
    /* ... 其他变量 */
}
```

### 添加功能
在 `app.js` 中添加新的函数和页面渲染逻辑。主要模块包括：
- `AppState`: 应用状态管理
- `renderCurrentPage()`: 页面渲染
- `switchTab()`: 页面切换
- 各个页面的渲染函数

## 注意事项

1. **数据安全**：本应用仅供演示使用，不应用于存储敏感医疗信息
2. **数据备份**：定期使用"导出数据"功能备份重要信息
3. **浏览器支持**：需要现代浏览器支持ES6语法和localStorage
4. **隐私保护**：所有数据仅存储在本地，不会上传到服务器
