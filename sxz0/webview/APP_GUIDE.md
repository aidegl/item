# 陪诊小程序使用指南

## 应用概述

这是一个面向职业陪诊师的智能辅助工具,通过AI技术实现诊前、诊中、诊后全流程的智能化管理。

## 核心功能

### 1. 智能体 (AI助手)
- **每诊提醒助手**: 自动记录患者复诊信息并提醒
- **日程管理**: 查看每日陪诊安排
- **任务跟踪**: 实时跟踪就诊进度

### 2. 患者库管理
- **患者档案**: 完整记录患者基本信息、过敏史、病史
- **快速搜索**: 按姓名或疾病快速查找患者
- **添加患者**: 便捷的患者信息录入表单

### 3. 完整的陪诊流程

#### 第一步: 诊前准备
1. 从患者列表选择患者,点击"开始新陪诊"
2. 进入"诊前沟通"页面,点击"开始诊前通话"
3. 系统自动录音,屏幕显示话术提示
4. 通话结束后,AI自动转写并提取关键信息

#### 第二步: 就诊需求书
1. AI已自动填充部分内容(基于录音转写)
2. 核对并补充完整信息:
   - 就诊类型(首诊/复诊)
   - 核心诉求
   - 症状详情
   - 既往诊疗情况
   - 患者核心疑问
3. 点击"保存就诊需求书"

#### 第三步: 诊中记录
1. **拍摄门诊病历**: OCR自动识别诊断和医嘱
2. **拍摄检查报告**: 自动提取异常指标
3. **语音备忘录**: 记录医生口头嘱咐
4. **手动补充**: 输入其他重要信息
5. 核对OCR识别结果并修改
6. 点击"生成诊后报告"

#### 第四步: 诊后报告
1. 系统自动生成完整的诊疗总结报告,包括:
   - 患者基本信息
   - 诊前核心信息回顾
   - 诊中诊疗详情(诊断、检查结果、治疗建议、药物处方)
   - 后续注意事项(生活方式调整、复诊安排)
2. 导出PDF或分享给患者

### 4. 备忘录
- 查看所有就诊记录
- 按状态筛选(已完成/进行中/已预约)
- 快速访问历史报告

### 5. 设置
- 个人信息管理
- AI咨询额度查看
- 订单管理
- 隐私安全设置

## 核心优势

### 🎯 智能化
- **AI语音转写**: 自动将诊前通话转为文字
- **OCR识别**: 智能识别病历和检查报告
- **自动填充**: 基于AI提取的信息自动填充表单
- **一键生成报告**: 自动整合所有信息生成专业报告

### ⚡ 高效化
- **减少80%手动录入**: 大部分信息由AI自动处理
- **话术提示**: 新手也能专业沟通
- **数据联动**: 一次录入,多处复用
- **快速导出**: 一键生成PDF报告

### 🛡️ 标准化
- **流程引导**: 按步骤完成,不遗漏关键环节
- **模板化表单**: 确保信息采集完整
- **专业报告**: 统一格式,提升服务质量
- **过敏提醒**: 重要信息高亮显示

## 新手引导

首次打开应用会显示4步新手引导:
1. **诊前沟通**: 了解智能通话录音功能
2. **就诊需求书**: 了解AI预填充功能
3. **诊中记录**: 了解OCR识别功能
4. **诊后报告**: 了解报告生成功能

可以随时在设置中重新查看引导。

## 数据安全

- 所有患者信息本地存储
- 符合医疗数据隐私保护要求
- 不适用于收集PII或敏感数据

## 技术特性

- **响应式设计**: 适配移动端使用
- **离线缓存**: 部分功能支持离线使用
- **实时保存**: 自动保存工作进度
- **快速加载**: 优化的性能表现

## 使用提示

1. **诊前通话**: 建议在安静环境中进行,确保录音质量
2. **OCR拍摄**: 保持光线充足,字体清晰,避免反光
3. **信息核对**: AI识别后务必人工核对,确保准确性
4. **及时保存**: 完成每个步骤后及时保存
5. **定期备份**: 重要报告建议导出备份

## 常见问题

**Q: AI识别错误怎么办?**
A: 所有AI识别的内容都可以手动修改,请仔细核对后再保存。

**Q: 可以跳过某些步骤吗?**
A: 建议按完整流程操作以确保服务质量,但部分可选项可以留空。

**Q: 如何查看历史记录?**
A: 在"备忘录"标签页查看所有历史就诊记录。

**Q: 报告可以修改吗?**
A: 生成报告前所有内容都可修改,生成后建议重新生成而不是直接修改。
