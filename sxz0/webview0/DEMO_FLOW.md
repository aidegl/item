# 陪诊小程序演示流程

## 🎬 快速演示

### 首次使用
1. 打开应用,自动显示**新手引导**
2. 浏览4个核心功能介绍页面
3. 点击"开始使用"进入主界面

### 演示场景: 为患者"张小梅"完成一次完整陪诊

#### 步骤1: 准备工作
1. 点击底部导航 **"患者库"**
2. 在患者列表中找到"张小梅"
3. 点击进入患者详情页
4. 查看患者信息(包括过敏史提醒)
5. 点击 **"开始新陪诊"** 按钮

#### 步骤2: 诊前沟通 (模拟AI录音转写)
1. 进入"诊前沟通"页面
2. 浏览话术提示(5个诊前问卷要点)
3. 点击 **"开始诊前通话"**
4. 屏幕切换为录音界面,显示:
   - 实时计时器
   - 话术提词器
5. 等待5秒(模拟通话)
6. 自动进入"AI智能转写中"状态
7. 2秒后自动跳转到就诊需求书

#### 步骤3: 就诊需求书 (AI已预填充)
1. 看到绿色提示框:"AI已自动填充部分内容"
2. 查看已预填充的字段:
   - 核心诉求: "患者主诉胸闷、心慌,担心心脏问题"
   - 症状名称: "胸闷、心慌"
   - 起病时间: "3天前"
   - 症状变化规律: "劳累后加重,休息后缓解"
3. 选择就诊类型: **首诊**
4. 补充其他信息(可选):
   - 诱发因素
   - 缓解因素
5. 点击 **"保存就诊需求书"**

#### 步骤4: 诊中记录 (OCR识别演示)
1. 进入"诊中记录"页面
2. 点击 **"拍摄门诊病历"** (模拟OCR)
3. 1.5秒后自动进入"OCR识别结果"页面
4. 查看自动识别的内容:
   - 最终诊断: "冠状动脉供血不足"
   - 医生治疗建议: 包含口服药物、定期复查等
   - 药物处方: 阿司匹林、辛伐他汀等
   - 生活方式调整: 静养、清淡饮食等
   - 下次复诊时间: "2周后复诊"
5. 可以手动修改任何识别结果
6. (可选)点击 **"拍摄检查报告"** 添加异常指标
7. 点击 **"生成诊后报告"**

#### 步骤5: 诊后报告
1. 查看完整的诊疗总结报告:
   - 蓝色渐变标题
   - 患者基本信息(含过敏提醒)
   - 一、诊前核心信息回顾
   - 二、诊中诊疗详情
   - 三、后续注意事项
2. 点击 **"导出PDF"** 或 **"发送患者"**
3. 返回主界面

### 其他功能演示

#### 患者库功能
1. 点击 **"患者库"** 标签
2. 使用搜索框搜索患者
3. 点击右上角 **"+"** 添加新患者:
   - 填写基本信息(姓名、性别、年龄、手机)
   - 填写药物过敏史(带警告提示)
   - 填写主要症状
4. 保存后返回列表

#### 备忘录功能
1. 点击 **"备忘录"** 标签
2. 查看所有就诊记录
3. 记录显示不同状态:
   - 绿色: 已完成诊后报告
   - 黄色: 进行中
   - 蓝色: 已预约
4. 点击任一记录查看详情

#### AI助手功能
1. 点击 **"智能体"** 标签
2. 查看今日复诊提醒
3. 查看即将到来的提醒列表
4. 点击右下角 **"+"** 添加新提醒

#### 设置功能
1. 点击 **"设置"** 标签
2. 查看AI咨询额度卡片
3. 浏览功能选项:
   - 订单管理
   - 隐私安全
   - 用户协议
   - 优惠码
4. 点击"退出登录"

## 🎯 演示要点

### 智能化特性
- ✅ **AI语音转写**: 诊前通话自动转文字
- ✅ **智能预填充**: 基于转写结果自动填充表单
- ✅ **OCR识别**: 自动识别病历和检查报告
- ✅ **一键生成**: 自动整合信息生成专业报告

### 用户体验亮点
- ✅ **新手引导**: 4步引导了解核心功能
- ✅ **话术提示**: 诊前沟通提供专业话术
- ✅ **上下文帮助**: 表单字段提供Tooltip提示
- ✅ **过敏高亮**: 重要信息红色醒目显示
- ✅ **流程化设计**: 按步骤引导,不遗漏环节

### 数据联动
- ✅ **患者信息**: 从患者库自动导入到就诊需求书
- ✅ **AI转写**: 自动填充到就诊需求书
- ✅ **OCR识别**: 自动填充到诊后报告
- ✅ **就诊需求**: 自动引用到诊后报告

## 📊 典型使用数据

- **传统方式**: 手动记录需要30-45分钟
- **使用本应用**: 
  - 诊前沟通: 5分钟(AI自动转写)
  - 就诊需求书: 3分钟(已预填充,仅需核对)
  - 诊中记录: 2分钟(OCR自动识别)
  - 诊后报告: 1分钟(一键生成)
  - **总计**: 约11分钟,**节省60%+时间**
