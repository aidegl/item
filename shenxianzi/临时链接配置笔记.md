# 临时文件链接功能配置笔记

## 1. 问题背景

我们需要实现一个功能：
- 用户通过前端上传文件（图片/PDF）
- 后端生成临时访问链接
- 外部服务（如OCR工作流）通过链接访问文件
- 文件自动清理（24小时后）

## 2. 技术栈

- 前端：HTML + JavaScript
- 后端：PHP 8.2
- 服务器：Nginx
- 部署环境：宝塔面板（Alibaba Cloud）

## 3. 解决方案概述

1. **创建PHP上传处理脚本**：接收文件并返回临时链接
2. **配置Nginx**：支持直接访问临时文件
3. **设置自动清理**：定时删除过期文件
4. **前端集成**：调用API生成临时链接

## 4. 详细配置步骤

### 4.1 创建上传处理脚本（api/tmp.php）

```php
<?php
// 设置CORS头
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: POST');
header('Access-Control-Allow-Headers: Content-Type');

// 设置返回JSON格式
header('Content-Type: application/json; charset=utf-8');

// 检查请求方法
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    echo json_encode(['error' => 'method_not_allowed'], JSON_UNESCAPED_UNICODE);
    exit;
}

// 检查是否有文件上传
if (!isset($_FILES['file'])) {
    echo json_encode(['error' => 'no_file'], JSON_UNESCAPED_UNICODE);
    exit;
}

$file = $_FILES['file'];

// 检查文件是否上传成功
if ($file['error'] !== UPLOAD_ERR_OK) {
    echo json_encode(['error' => 'upload_failed', 'code' => $file['error']], JSON_UNESCAPED_UNICODE);
    exit;
}

// 检查文件大小（限制50MB）
if ($file['size'] > 50 * 1024 * 1024) {
    echo json_encode(['error' => 'file_too_large'], JSON_UNESCAPED_UNICODE);
    exit;
}

// 检查文件类型
$allowedTypes = ['image/jpeg', 'image/png', 'image/gif', 'image/webp', 'application/pdf'];
if (!in_array($file['type'], $allowedTypes)) {
    echo json_encode(['error' => 'invalid_file_type'], JSON_UNESCAPED_UNICODE);
    exit;
}

// 创建目标目录
$destDir = '/www/wwwroot/100000whys.cn/project/shenxianzi/webview/dist/tmp';
if (!is_dir($destDir)) {
    mkdir($destDir, 0755, true);
    chown($destDir, 'www');
    chgrp($destDir, 'www');
}

// 生成唯一文件名
$ext = pathinfo($file['name'], PATHINFO_EXTENSION);
$uniqueName = date('Ymd_His_') . uniqid() . '.' . $ext;
$savePath = $destDir . '/' . $uniqueName;

// 移动文件
if (!move_uploaded_file($file['tmp_name'], $savePath)) {
    echo json_encode(['error' => 'move_file_failed'], JSON_UNESCAPED_UNICODE);
    exit;
}

// 设置文件权限
chmod($savePath, 0644);
chown($savePath, 'www');
chgrp($savePath, 'www');

// 生成临时访问URL
$url = 'https://100000whys.cn/project/shenxianzi/webview/dist/tmp/' . $uniqueName;

// 返回结果
echo json_encode([
    'success' => true,
    'url' => $url,
    'filename' => $uniqueName,
    'message' => '上传成功'
], JSON_UNESCAPED_UNICODE);
?>
```

### 4.2 配置Nginx（网站设置 -> 配置文件）

```nginx
# 允许访问 tmp 目录中的临时文件
location ^~ /project/shenxianzi/webview/dist/tmp/ {
    alias /www/wwwroot/100000whys.cn/project/shenxianzi/webview/dist/tmp/;

    # 允许直接访问文件
    autoindex off;

    # 设置正确的 MIME 类型
    types {
        image/jpeg jpg jpeg;
        image/png png;
        image/gif gif;
        image/webp webp;
        application/pdf pdf;
    }

    # 添加缓存控制（防止浏览器缓存）
    add_header Cache-Control "no-cache, no-store, must-revalidate";
    add_header Pragma "no-cache";
    add_header Expires "0";
}

# 将 /api/upload 映射到 /api/tmp.php
location = /api/upload {
    rewrite ^/api/upload$ /api/tmp.php last;
}

# 确保PHP 8.2配置正确
include enable-php-82.conf;
```

### 4.3 设置自动清理脚本（api/cleanup_tmp.php）

```php
<?php
// 临时文件目录
$tmpDir = '/www/wwwroot/100000whys.cn/project/shenxianzi/webview/dist/tmp';

// 最大文件年龄（秒）：24小时
$maxAge = 24 * 60 * 60;

// 当前时间戳
$now = time();

// 打开目录
$dir = opendir($tmpDir);

// 遍历文件
while (($file = readdir($dir)) !== false) {
    // 跳过系统文件
    if ($file === '.' || $file === '..') {
        continue;
    }

    // 文件路径
    $filePath = $tmpDir . '/' . $file;

    // 检查是否为文件
    if (is_file($filePath)) {
        // 获取文件修改时间
        $fileTime = filemtime($filePath);

        // 检查文件是否过期
        if ($now - $fileTime > $maxAge) {
            // 删除文件
            unlink($filePath);
        }
    }
}

// 关闭目录
closedir($dir);

// 输出结果
echo "临时文件清理完成！";
?>
```

### 4.4 配置定时清理任务（宝塔面板）

3. 点击 **添加任务**

   - 任务名称：**清理临时文件**
   - 执行周期：**每天**
   - 执行时间：**00:00**
   - 脚本内容：
     ```bash
     /usr/bin/php /www/wwwroot/100000whys.cn/api/cleanup_tmp.php
     ```

### 4.5 前端集成代码

```javascript
window.ocrUploadAndGetLink = async () => {
    try {
        const input = document.createElement('input');
        input.type = 'file';
        input.accept = 'image/*,application/pdf';
        input.onchange = async () => {
            const file = input.files && input.files[0];
            if (!file) return;
            const fd = new FormData();
            fd.append('file', file);
            const resp = await fetch('https://100000whys.cn/api/upload', { method: 'POST', body: fd });
            const ct = resp.headers.get('content-type') || '';
            const isJson = ct.includes('application/json');
            const data = isJson ? await resp.json() : await resp.text();
            let url = '';
            if (isJson && data && (data.url || data.link)) {
                url = data.url || data.link;
            } else if (typeof data === 'string') {
                try { const j = JSON.parse(data); url = j.url || j.link || ''; } catch (_) {}
            }
            if (!url) {
                err('OCR链接', '上传失败或未返回链接', data);
                return;
            }
            log('OCR链接', '生成外部可访问临时链接', { url });
            const logEl = document.getElementById('app-logs');
            if (logEl) {
                const line = document.createElement('div');
                const a = document.createElement('a');
                a.href = url;
                a.target = '_blank';
                a.textContent = url;
                line.style.margin = '6px 0';
                line.appendChild(document.createTextNode('外部链接：'));
                line.appendChild(a);
                logEl.appendChild(line);
            }
            if (navigator.clipboard && navigator.clipboard.writeText) {
                navigator.clipboard.writeText(url).catch(() => {});
            }
        };
        input.click();
    } catch (e) {
        err('OCR链接', '生成失败', e);
    }
}
```

#### 前端代码说明

1. **文件选择**：
   - 创建隐藏的文件输入框
   - 限制只能选择图片和PDF文件
   - 通过`input.click()`触发文件选择对话框

2. **文件上传**：
   - 使用`FormData`构造表单数据
   - 通过`fetch`发送POST请求到`/api/upload`
   - 自动处理文件二进制数据

3. **响应处理**：
   - 智能检查响应是否为JSON格式
   - 支持多种URL返回格式（`url`或`link`字段）
   - 处理非JSON响应的降级情况

4. **结果展示**：
   - 将临时链接显示到日志区域
   - 提供可点击的链接（新窗口打开）
   - 自动复制链接到剪贴板

5. **错误处理**：
   - 捕获并记录所有可能的错误
   - 提供友好的错误提示
   - 确保上传失败时有明确反馈

## 7. 故障排查

### 7.1 502 Bad Gateway错误

**原因**：Nginx无法与PHP-FPM通信

**解决方法**：
1. 检查Nginx配置中的PHP版本：`include enable-php-82.conf;`
2. 检查PHP-FPM状态：宝塔 -> 软件商店 -> PHP 8.2 -> 服务
3. 检查PHP-FPM配置：`listen = /tmp/php-cgi-82.sock`

### 7.2 文件无法上传

**可能原因**：
1. PHP上传限制：检查`upload_max_filesize`（50M）
2. 文件权限：tmp目录必须有写入权限
3. 文件类型：检查是否为允许的类型

### 7.3 临时链接无法访问

**可能原因**：
1. Nginx配置错误：检查location块
2. 文件路径错误：确保alias路径正确
3. 文件权限：确保文件有读取权限
