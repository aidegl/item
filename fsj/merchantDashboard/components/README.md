# 组件目录说明

本目录包含门店装修系统中的所有可视化组件，每个组件都可以在装修页面中拖拽使用。

## 组件分类

### 系统级组件
- **特点**：有各自独立的数据表，调用数据方法直接在组件定义中
- **数据源**：直接从对应业务表加载
- **配置**：不需要用户配置数据来源，直接使用系统预置数据
- **包含组件**：轮播图、功能列表、商品网格、内容列表

### 用户级组件
- **特点**：统一使用 `neirong` 数据表，需要用户配置跳转和样式
- **数据源**：从 `neirong` 表加载，支持按需加载
- **配置**：需要用户配置数据内容和样式，灵活性高
- **包含组件**：图片、文本、公告、标签页

## 组件列表

### 1. componentRegistry.js - 组件注册中心
**作用**：组件注册和管理系统

**说明**：
- 提供组件注册功能 `registerComponent(name, component)`
- 提供组件获取功能 `getComponent(name)`
- 提供获取所有组件功能 `getAllComponents()`
- 作为组件系统的核心，管理所有可用组件

---

### 2. carousel.js - 轮播图组件
**类型**：系统级组件

**作用**：展示自动轮播的图片内容

**功能特性**：
- 支持多张图片轮播展示
- 可配置轮播高度
- 支持自动播放开关
- 可设置轮播间隔时间
- 显示轮播指示器

**可配置属性**：
- `height`：轮播图高度（默认200px）
- `autoplay`：是否自动播放（默认true）
- `interval`：轮播间隔时间（默认3000ms）

**数据加载**：
- **数据源**：`lunbotu` 表
- **数据格式**：组件项为对象数组，每个对象包含 `url` 字段（封面图URL）
- **配置方式**：系统自动加载，无需用户配置
- **加载方式**：从 `lunbotu` 表加载轮播图数据

**使用场景**：首页Banner、活动宣传、产品展示

---

### 3. function-list.js - 功能列表组件
**类型**：系统级组件

**作用**：展示功能入口的网格布局

**功能特性**：
- 支持自定义列数（默认3列）
- 每个功能项显示图标和名称
- 网格布局自动适配
- 支持自定义功能项数量

**可配置属性**：
- `columns`：列数（默认3）
- `iconSize`：图标大小（默认48px）

**数据加载**：
- **数据源**：功能列表表
- **数据格式**：组件项为对象数组，每个对象包含 `icon`（图标URL）和 `name`（功能名称）字段
- **配置方式**：系统自动加载，无需用户配置
- **加载方式**：从功能列表表加载功能项数据

**使用场景**：首页功能导航、快捷入口、服务分类

## 组件开发规范

每个组件需要实现以下方法：

```javascript
module.exports = {
  name: '组件名称',
  type: '组件类型',

  generateHTML(component) {
    // 生成小程序WXML代码
  },

  generateCSS() {
    // 生成小程序WXSS样式
  },

  getDefaultProperties() {
    // 返回默认属性配置
  },

  getDefaultItems() {
    // 返回默认内容项
  },

  getPropertyLabels() {
    // 返回属性标签映射
  },

  async loadData(merchantId, outputDir) {
    // 系统级组件实现此方法，从明道云加载数据
    // 返回格式化后的数据数组
    // 可选方法，用户级组件不需要实现
  }
};
```

### 方法说明

#### 必需方法
- **generateHTML(component)**：生成小程序 WXML 代码
- **generateCSS()**：生成小程序 WXSS 样式
- **getDefaultProperties()**：返回默认属性配置对象
- **getDefaultItems()**：返回默认内容项数组
- **getPropertyLabels()**：返回属性标签映射对象

#### 可选方法
- **loadData(merchantId, outputDir)**：系统级组件实现，从明道云加载数据
  - 在打包时由后端调用
  - 负责从明道云加载组件数据
  - 下载相关图片到 `images` 目录
  - 返回格式化后的数据，供 `generateHTML` 使用

### 组件职责划分
- **系统级组件**（轮播图、功能列表、商品网格、内容列表）：必须实现 `loadData` 方法
- **用户级组件**（图片、文本、公告、标签页）：不需要实现 `loadData` 方法

## 数据绑定与加载

### 数据格式说明

组件的 `componentItems` 字段支持两种数据格式：

#### 1. 动态数据（推荐）
使用明道云 `neirong` 表的 rowid，小程序根据 rowid 动态加载实际内容。

**单条数据格式**：
```json
{
  "componentItems": "5bdc6e9d-53ff-446b-80b4-461802349783"
}
```

**多条数据格式**：
```json
{
  "componentItems": [
    "5bdc6e9d-53ff-446b-80b4-461802349783",
    "16e1d3ff-50e6-494c-ac07-4049183ba4f7",
    "a3b4c5d6-e7f8-9012-bcde-f12345678901"
  ]
}
```

**优势**：
- 内容更新无需重新打包小程序
- 支持实时数据同步
- 便于算法推荐和权重排序

#### 2. 静态数据
适用于功能列表等静态文本内容。

**格式**：
```json
{
  "componentItems": ["圈子", "想法", "团送"]
}
```

### 数据来源配置

所有组件支持数据绑定功能：

- **通用数据来源**：商品、文章、知识库
- **自定义数据来源**：自定义数据

### 小程序端数据加载

小程序根据 `componentItems` 中的 rowid 从明道云 `neirong` 表加载数据：

```javascript
async function loadComponentContent(component) {
  const rowids = Array.isArray(component.componentItems) 
    ? component.componentItems 
    : [component.componentItems];
  
  const api = new MingDaoYunArrayAPI();
  
  const params = {
    worksheetId: 'neirong',
    filters: [
      {
        controlId: 'rowid',
        dataType: 2,
        spliceType: 2,
        filterType: 24,
        value: rowids
      }
    ]
  };
  
  const result = await api.getData(params);
  
  if (result.success && result.data && result.data.rows) {
    return result.data.rows;
  }
  
  return [];
}
```

### 排序规则

**通用数据来源**：
- 权重
- 发布时间正序
- 发布时间倒序
- 更新时间正序
- 更新时间倒序

**自定义数据来源**：
- 算法推荐（基于neirong表的权重计算）

**实现说明**：
- 排序规则UI已实现在 `decoration.html` 中
- 通过 `getSortingOptionsHtml` 函数根据数据来源类型动态生成排序选项
- 通过 `updateComponentSorting` 函数保存排序规则到组件配置的 `sorting` 字段
- 排序规则会根据数据来源类型自动切换显示对应的选项

## 组件使用流程

1. 在装修页面左侧组件库中拖拽组件到画布
2. 在右侧属性面板配置组件属性
3. 设置数据来源和排序规则
4. 预览效果并保存配置

## 注意事项

- 组件配置会保存到localStorage
- 组件生成的小程序代码需要配合对应的小程序框架使用
- 图片资源需要确保可访问
- 组件样式可根据主题色自动适配
