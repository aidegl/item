# 内容列表组件规划

## 组件概述

内容列表组件是一个支持标签页切换的文章/内容展示组件，适用于文章列表、新闻列表、商品推荐等场景。

## 组件名称

**内容列表** (content-list)

---

## 功能特性

### 1. 标签页功能

| 特性     | 说明                   |
| -------- | ---------------------- |
| 标签类型 | 全部 + 自定义过滤标签  |
| 过滤方式 | 明道云数据表字段值过滤 |
| 分页支持 | 每个标签独立分页       |
| 标签数量 | 支持多个自定义标签     |
| 默认选中 | 可设置默认选中的标签   |

### 2. 主题色配置

| 特性     | 说明                   |
| -------- | ---------------------- |
| 来源     | 继承全局样式主题色     |
| 自定义   | 支持单独设置标签主题色 |
| 应用范围 | 标签选中状态、下划线等 |

---

## 列表字段映射

| 字段     | 说明       | 数据类型     |
| -------- | ---------- | ------------ |
| 标题     | 内容标题   | string       |
| 描述     | 内容摘要   | string       |
| 封面     | 封面图片   | image        |
| 标签组   | 内容标签   | array/string |
| 价格     | 内容价格   | number       |
| 作者头像 | 发布者头像 | image        |
| 作者昵称 | 发布者名称 | string       |
| 发布日期 | 发布时间   | date         |

---

## 时间显示格式

### 特殊时间显示

| 时间范围 | 显示格式 |
| -------- | -------- |
| < 1小时  | N分钟前  |
| < 24小时 | N小时前  |
| 昨天     | 昨天     |
| < 7天    | N天前    |

### 常规时间显示

| 时间范围 | 显示格式   |
| -------- | ---------- |
| >= 7天   | 2015-10-10 |

## 数据源配置

### 明道云数据表

- **工作表别名**: 用户配置
- **过滤字段**: 用户选择标签对应的字段
- **排序字段**: 发布日期（倒序）

### API 请求参数

```javascript
{
  worksheetId: '用户配置的工作表',
  filters: [
    {
      controlId: '标签字段',
      dataType: 数据类型,
      spliceType: 1,
      filterType: 过滤类型,
      value: 标签值
    }
  ],
  pageSize: 10,
  pageIndex: 页码
}
```

## 组件属性配置

| 属性              | 说明                   | 默认值        |
| ----------------- | ---------------------- | ------------- |
| worksheetId       | 数据表别名             | -             |
| titleField        | 标题字段               | title         |
| descField         | 描述字段               | description   |
| coverField        | 封面字段               | cover         |
| tagsField         | 标签组字段             | tags          |
| priceField        | 价格字段               | price         |
| authorAvatarField | 作者头像字段           | author_avatar |
| authorNameField   | 作者昵称字段           | author_name   |
| dateField         | 发布日期字段           | publish_date  |
| themeColor        | 主题色（空则继承全局） | -             |
| defaultTab        | 默认选中标签           | 全部          |

## 列表样式

### 默认布局

```
┌─────────────────────────────────────┐
│ [全部] [标签1] [标签2] [标签3]      │ ← 标签栏（可滚动）
├─────────────────────────────────────┤
│ ┌────────┐                          │
│ │  封面  │  标题标题                │
│ │ 150x90 │  描述内容...             │
│ └────────┘  标签1 标签2   ¥99.00   │
│                           👤作者   │
│ ─────────────────────────────────  │
│ (内容重复...)                        │
└─────────────────────────────────────┘
```

### 样式变量

- 封面尺寸: 150px × 90px
- 标题行数: 2行
- 描述行数: 2行
- 标签间距: 8px
- 列表间距: 12px

---

## 标签页数据结构

### 配置示例

```javascript
{
  tabs: [
    { label: '全部', value: '' },
    { label: '推荐', field: 'status', value: 'recommended' },
    { label: '最新', field: 'category', value: 'new' }
  ]
}
```

### API 过滤逻辑

- **全部**: 无过滤条件
- **自定义标签**: 根据 field 和 value 构建过滤条件
