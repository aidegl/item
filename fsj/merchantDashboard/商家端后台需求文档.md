```javascript

```

1. 从 localStorage 获取商家数据
2. 解析 logo 字段的 JSON 字符串
3. 获取第一个 logo 对象的完整图片路径

### 门店装修功能（decoration）

#### 功能概述
门店装修是一个可视化页面设计器，商家可以通过拖拉拽组件来设计小程序页面，无需编写代码。

#### 页面布局
```
┌─────────────────────────────────────────────────────────┐
│  页面树（左侧）          │  组件库（中间）        │  属性面板（右侧）  │
│  ├─ 首页                  │  [轮播图]              │  组件名称：轮播图    │
│  ├─ 分类                  │  [功能列表]            │  高度：200          │
│  └─ 我的                  │  [图片]                │  自动播放：是        │
│                          │  [文本]                │  间隔：3000         │
│  [新增页面]               │  [商品网格]            │                    │
│                          │  [公告]                │  [删除组件]         │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
                  ┌──────────────────┐
                  │  预览区域      │
                  │  （手机模拟）    │
                  └──────────────────┘
```

#### 页面树功能
- 显示所有已创建的页面
- 支持页面重命名
- 支持页面删除
- 支持页面复制
- 支持新增页面

#### 组件库功能
- 显示所有可用组件
- 支持拖拉拽到页面
- 组件分类展示

#### 属性面板功能
- 显示选中组件的属性
- 支持属性编辑
- 实时预览属性变化
- 支持组件删除

#### 预览区域功能
- 实时预览页面效果
- 手机模拟器（375px × 667px）
- 支持切换设备尺寸
- 支持预览底部导航栏

#### 组件拖拉拽
- 从组件库拖拽组件到页面
- 支持组件排序（拖动排序）
- 支持组件删除
- 支持组件属性编辑

#### 代码生成流程
1. 商家通过可视化编辑器设计页面
2. 生成JSON配置文件
3. 调用后端API生成小程序代码
4. 打包成ZIP文件
5. 商家下载代码包
6. 使用微信开发者工具导入并上传

### 混合打包方案

#### 方案说明
采用**混合打包模式**，结合基础框架代码和动态配置的优势：

1. **基础框架代码**（wxApp 目录）
   - 通过 git 同步到宝塔
   - 包含通用组件、工具类、基础配置
   - 统一管理，便于维护和更新

2. **页面配置**（明道云）
   - 商家设计的页面 JSON 配置
   - 组件属性设置
   - 底部导航栏配置

3. **打包逻辑**（后端）
   - 复制基础框架代码
   - 根据配置生成页面代码
   - 生成 app.json（配置页面路径和 tabBar）
   - 打包成 ZIP

#### 打包流程
```
1. 商家在门店装修页面设计页面
   ↓
2. 生成 JSON 配置并保存到明道云
   ↓
3. 点击"发布新版本"按钮
   ↓
4. 调用后端 API（POST /api/generate-miniprogram）
   ↓
5. 后端复制 wxApp 基础框架代码
   ↓
6. 后端根据配置生成页面代码（使用模板）
   ↓
7. 后端生成 app.json（配置页面路径和 tabBar）
   ↓
8. 后端打包成 ZIP 文件
   ↓
9. 商家下载 ZIP 文件
   ↓
10. 使用微信开发者工具导入并上传
```

#### 优势
- **灵活性**：商家可以自由设计页面，不受固定模板限制
- **可维护性**：基础框架代码统一管理，便于更新
- **性能**：基础代码直接复制，只生成页面代码，速度快
- **版本控制**：基础代码通过 git 管理，配置存储在明道云
- **可扩展**：新增组件只需更新模板，不影响现有功能

#### 后端 API 说明

##### POST /api/generate-miniprogram
生成小程序代码包

**请求参数**：
```json
{
  "merchantId": "123456",
  "config": {
    "globalConfig": [...],
    "tabBarConfig": [...],
    "pages": [...]
  }
}
```

**返回**：ZIP 文件流

##### POST /api/save-config
保存页面配置到明道云

**请求参数**：
```json
{
  "merchantId": "123456",
  "config": {
    "globalConfig": [...],
    "tabBarConfig": [...],
    "pages": [...]
  }
}
```

**返回**：
```json
{
  "success": true,
  "message": "保存成功"
}
```

##### GET /api/load-config
加载页面配置

**请求参数**：
```
?merchantId=123456
```

**返回**：
```json
{
  "success": true,
  "data": {
    "globalConfig": [...],
    "tabBarConfig": [...],
    "pages": [...]
  }
}
```

### 底部导航栏样式

- 背景色：#ffffff

- 图标大小：48rpx
- 边框：顶部1px #e0e0e0
- 字体大小：24rpx

- 背景色：#f8f9fa
- 文字色：#6c757d（未选中）、#007bff（选中）
- 图标大小：52rpx
- 边框：无，使用阴影
