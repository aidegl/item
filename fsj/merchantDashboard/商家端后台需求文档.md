### 开发说明
不能有光标闪烁和选中字体

### 显示逻辑
每个列表板块对应一个页面，页面作为自定义视图嵌入明道云

#### 列表
列表包含首页、店铺管理、商品管理、订单管理、配送管理、会员管理、智慧营销、圈子管理、内容管理、系统设置

##### 首页
1.店铺信息
2.运营数据：用户数量、订单数量、配送数量、会员数量
3.常用功能
4.营销功能
5.代码发布

##### 店铺管理
包含子菜单店铺资料、门店管理、下单设置、更多设置、图片空间
门店管理 (store)
商品管理 (product)
订单管理 (order)
配送管理 (delivery)
会员管理 (member)
智慧营销 (marketing)
圈子管理 (circle)
内容管理 (content)
系统设置 (system)

#### 数据交互
根据url参数显示不同用户的数据，每个列表板块对应一个页面，页面作为自定义视图嵌入明道云
获取商家id：?mRowid=123456；

##### 明道云返回数据结构
```json
{
  "success": true,
  "data": {
    "rows": [
      {
        "rowid": "6987e4a94a70f651557bceea",
        "mingcheng": "示例店铺",
        "leixing": "综合商城",
        "zhuangtai": 1,
        "logo": "[{\"large_thumbnail_full_path\":\"https://example.com/logo.png\"}]"
      }
    ],
    "total": 1
  },
  "error_msg": "",
  "error_code": 1
}
```

**注意**：部分字段（如 logo）返回的是 JSON 字符串，需要使用 `JSON.parse()` 解析。

##### 图片取值方式
所有图片的取值统一使用：
```javascript
JSON.parse(localStorage.getItem('merchantData')).logo[0].large_thumbnail_full_path
```

**说明**：
1. 从 localStorage 获取商家数据
2. 解析 logo 字段的 JSON 字符串
3. 获取第一个 logo 对象的完整图片路径
