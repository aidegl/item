### 开发说明
不能有光标闪烁和选中字体

### 显示逻辑
每个列表板块对应一个页面，页面作为自定义视图嵌入明道云

#### 列表
列表包含首页、店铺管理、商品管理、订单管理、配送管理、会员管理、智慧营销、圈子管理、内容管理、系统设置

##### 首页
1.店铺信息
2.运营数据：用户数量、订单数量、配送数量、会员数量
3.常用功能
4.营销功能
5.代码发布

##### 店铺管理
包含子菜单店铺资料、门店管理、下单设置、更多设置、图片空间
商品管理
订单管理
配送管理
会员管理
智慧营销
圈子管理
内容管理
系统设置

#### 数据交互
根据url参数显示不同用户的数据，每个列表板块对应一个页面，页面作为自定义视图嵌入明道云
获取商家id：?mRowid=123456；

### 变量定义

#### 全局变量
所有页面共享的变量

| 变量名 | 类型 | 描述 | 来源 | 示例 | 用途 |
|--------|------|------|------|------|------|
| merchantId | string | 商家ID，从URL参数mRowid获取 | URL参数 | 6987e4a94a70f651557bceea | 用于查询商家数据、权限验证 |
| userId | string | 用户ID，从URL参数userId获取 | URL参数 | user123 | 用户身份识别、操作日志 |
| merchantData | object | 商家完整数据，从明道云获取 | 明道云API | - | 存储商家基本信息、配置等 |
| apiBaseUrl | string | API基础URL | 配置 | https://api.mingdao.com | 所有API请求的基础地址 |
| version | string | 版本号，用于强制刷新资源 | URL参数或时间戳 | 1234567890 | 资源版本控制 |
