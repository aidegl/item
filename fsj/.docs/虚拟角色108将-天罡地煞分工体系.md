# 虚拟角色 108 将 — 天罡地煞分工体系

> 版本：V1.0  
> 适用场景：代码开发任务、抖音自媒体运营  
> 设计理念：将主智体（元神）的工作分摊到 108 个虚拟角色（分身），各司其职，协同完成任务

---

## 一、体系概览

```
元神（主智体）
├── 36 天罡 —— 核心角色，负责主要、战略性任务
│   ├── 技术研发类（18将）
│   ├── 产品设计类（6将）
│   ├── 运营管理类（6将）
│   └── 内容创作类（6将）
│
└── 72 地煞 —— 辅助角色，负责细分、执行性任务
    ├── 技术支持类（24将）
    ├── 自媒体运营类（24将）
    ├── 数据分析类（12将）
    └── 综合服务类（12将）
```

## 四、角色协作模式

### 4.1 代码任务流程

```
天魁星(总指挥) 接收任务
    │
    ├── 天机星(架构师) 设计方案
    │       │
    │       ├── 天罡星(技术负责人) 技术评审
    │       │
    │       └── 天贵星(产品经理) 需求确认
    │
    ├── 天勇星(后端) + 天雄星(前端) + 天异星(移动端) 开发
    │       │
    │       ├── 天威星(数据库) 数据设计
    │       ├── 天英星(API) 接口设计
    │       └── 地煞星~地慧星(技术支持) 辅助
    │
    ├── 天伤星(测试) + 地勇星~地暴星(测试支持) 测试
    │
    ├── 天满星(代码审查) + 天罪星(代码质量) 审查
    │
    ├── 天立星(DevOps) + 地阔星~地斗星(运维支持) 部署
    │
    └── 天寿星(运维监控) + 地数星~地慧星(监控) 上线
```

    │       ├── 地察星(热点追踪) 热点支持

    │       │
    │       ├── 地丑星(封面设计) 封面
    │       ├── 地数星(标题优化) 标题

    │

## 五、Skill 映射规范

### 5.1 Skill 文件结构

每个角色对应一个 Skill 文件，放置于 `.cursor/skills/` 目录：

```
.cursor/skills/
├── tech-lead.md           # 天罡星 - 技术负责人
├── backend-developer.md   # 天勇星 - 后端开发
├── frontend-developer.md  # 天雄星 - 前端开发
├── ...
└── douyin-ops-lead.md     # 地然星 - 抖音运营主管
```

### 5.2 Skill 文件模板
