## 表结构总览

### 圈子层级关系说明

本数据表结构基于**多层级圈子架构**设计，支持圈子的嵌套和层级关系：

1. **层级关系**：
   - 上级圈子：更高层级的组织或团队
   - 当前圈子：本级组织或团队
   - 下级圈子：更低层级的个人或子团队
2. **数据表命名规则**：
   - **组织圈数据表**：使用 `org_` 前缀，表示当前圈子的数据
   - **个人数据表**：不使用前缀，表示相对于上级圈子的个人数据
   - **注意**：个人数据表不一定是AI，也可能是真人用户
3. **层级示例**：
   ```
   公司（上级圈子）
     └── 技术部（当前圈子）
           ├── 张三（个人）
           ├── 李四（个人）
           └── AI智能体（个人）
   ```
4. **数据继承关系**：
   - 上级圈子的规则、制度可以下发给下级圈子
   - 个人数据表的数据可以汇总到组织圈数据表
   - 支持跨层级的数据查询和统计

## 宇宙观世界秩序设计理念

### 核心思想

基于天干地支哲学和道天地将法架构，构建AI智能体的宇宙观世界秩序：

1. **道（金）**：通过制度规则表体现，确定价值观和方向
2. **天（水）**：通过知识库表和财务表体现，收集数据和资源
3. **地（土）**：通过计划表和任务表体现，运化和执行
4. **将（木）**：通过技能表和产出表体现，行动和创造
5. **法（火）**：通过想法表和策略表体现，包装和创新

### 数据流转

#### 个人数据流转

```
个人规则表（道）→ 个人知识库表（天）→ 个人计划表（地）→ 个人任务表（将）→ 个人仓库表（法）
                    ↓                          ↓
                个人财务表（天）            个人技能表（将）
                    ↓                          ↓
                个人积分表（天）            个人想法表（法）
```

#### 组织圈数据流转

```
组织规则表（道）→ 组织知识库表（天）→ 组织规划表（地）→ 组织商品表（法）
                    ↓                          ↓
                组织财务表（天）            组织技能表（将）
                    ↓                          ↓
                组织积分表（天）            组织审核表（法）
```

#### 跨层级数据流转

```
个人仓库表 → 组织商品表（个人产出汇总为组织商品）
个人积分表 → 组织积分表（个人积分汇总为组织积分）
个人财务表 → 组织财务表（个人财务汇总为组织财务）
个人知识库表 → 组织知识库表（个人知识贡献到组织知识库）
```

### 五行平衡

#### 个人数据表五行平衡

- **木（将）**：个人技能表、个人任务表、个人仓库表 - 生长和行动
- **火（法）**：个人想法表、个人策略表 - 发散和创新
- **土（地）**：个人计划表、个人任务表 - 运化和承载
- **金（道）**：个人规则表 - 决断和规范
- **水（天）**：个人知识库表、个人财务表、个人积分表 - 收集和智慧

#### 组织圈数据表五行平衡

- **木（将）**：组织技能表、组织商品表 - 生长和行动
- **火（法）**：组织审核表 - 发散和创新
