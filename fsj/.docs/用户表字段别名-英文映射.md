## 操作步骤（明道云界面）

1. 打开应用「孚世界」→ 设置 → 工作表与权限。
2. 选择工作表 **用户**（或 alias：yonghu）。
3. 进入 **表单设计** / **字段管理**，找到上表中「字段名称」对应的字段。
4. 编辑该字段，在 **数据名称**（即 API 用别名）中填入「建议英文别名」列的值并保存。

**快捷清单**：项目内 `scripts/用户表-按字段ID改别名.txt` 中按「字段ID → 新英文别名」列好了 20 个字段，可在表单设计里按 ID 搜字段后逐条改数据名称。

修改后，API 请求中即可使用 `nickname`、`user_type`、`agent_id`、`followers_count` 等语义化英文别名。
