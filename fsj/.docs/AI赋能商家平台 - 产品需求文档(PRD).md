## 一、产品概述

### 1.1 产品定位
**AI赋能商家平台**是一个面向草根创业者的低代码小程序生成平台，通过可视化拖拉拽和AI辅助定制，让不懂代码的创业者也能快速搭建自己的小程序应用。平台内置AI卡牌训练等特色功能，帮助创业者提高工作效率、学习效率，并建立自己的商业圈子。

### 1.2 目标用户
- **主要用户**：草根创业者、对AI焦虑的人群
- **用户特征**：
  - 技术背景弱，希望快速搭建自己的应用
  - 需要AI工具提升工作效率
  - 希望通过圈子认识志同道合的人
  - 有定制化需求但预算有限
- **使用场景**：
  - 快速搭建自己的小程序商城
  - 部署AI助手提升服务效率
  - 建立自己的用户圈子
  - 学习AI知识并应用到业务中

### 1.3 核心价值
- **对创业者**：零代码搭建小程序，AI辅助降低开发成本，快速验证商业想法
- **对平台**：通过组件化和AI协同，逐步提升AI完成度，最终实现AI自动开发
- **对生态**：赋能创业者，降低创业门槛，促进创新

### 1.4 产品目标
- **MVP目标**：验证核心功能，获得100+商家用户
- **商业目标**：通过订阅和定制服务实现盈利
- **长期目标**：成为AI辅助低代码开发领域的领先平台，AI完成度达到99%

### 1.5 产品架构
平台由两部分组成：

#### 1.5.1 商家后台（merchantDashboard）
- **定位**：商家使用的后台管理系统
- **功能**：
  - 可视化页面设计器（拖拉拽组件）
  - 组件库（通用组件 + DIY组件）
  - 定制化需求管理（AI自动改 + 人工介入）
  - 小程序代码打包下载
- **部署**：嵌入明道云作为自定义视图

#### 1.5.2 小程序端（wxApp）
- **定位**：商家生成的小程序应用
- **功能**：
  - 通用功能：注册登录、轮播图、功能列表、商品网格、内容列表等
  - 特色功能：AI卡牌训练（通过Webview内嵌）
  - 商城功能：商品展示、订单管理等
- **部署**：商家下载代码包，导入微信开发者工具发布

#### 1.5.3 AI卡牌训练平台（特色功能）
- **定位**：通过Webview内嵌在小程序中的特色功能
- **功能**：
  - AI智能体训练（卡牌化）
  - AI分身创建
  - AI任务管理
  - AI知识库
  - 社交圈子
- **技术**：HTML5 + Canvas（像素化UI）

## 二、功能需求

### 2.1 商家后台系统

#### 2.1.1 用户认证
**功能描述**：商家通过URL参数访问后台

**需求详情**：
- 通过URL参数 `?mRowid=xxx` 识别商家
- 调用明道云API验证商家身份
- 加载商家配置到localStorage
- 显示商家专属数据

**验收标准**：
- 认证流程<2秒
- 支持自动登录（7天免登录）
- 数据加载<3秒

#### 2.1.2 门店装修（页面设计器）
**功能描述**：可视化拖拉拽设计小程序页面

**需求详情**：
- **页面树**：左侧显示页面列表，支持新增/删除/切换
- **组件库**：中间显示可用组件，支持拖拽到页面
- **属性面板**：右侧显示选中组件的属性，支持编辑
- **预览区域**：底部实时预览小程序页面效果
- **视图切换**：
  - 页面视图：设计页面内容
  - 底部导航栏视图：配置底部导航
  - 全局设置视图：配置全局样式

**验收标准**：
- 拖拽流畅，无卡顿
- 预览实时更新
- 支持组件排序

#### 2.1.3 组件系统
**功能描述**：提供丰富的组件库

**组件分类**：

##### 通用组件（系统默认）
1. **轮播图（carousel）**
   - 功能：自动轮播的图片内容
   - 可配置：高度、自动播放、轮播间隔
   - 使用场景：首页Banner、活动宣传

2. **功能列表（function-list）**
   - 功能：展示功能入口的网格布局
   - 可配置：列数
   - 使用场景：首页功能导航、快捷入口

3. **图片（image）**
   - 功能：展示单张图片
   - 可配置：高度、圆角
   - 使用场景：广告图、装饰图片

4. **文本（text）**
   - 功能：展示自定义文本
   - 可配置：字体大小、颜色、对齐方式
   - 使用场景：标题、说明文字

5. **商品网格（product-grid）**
   - 功能：以网格形式展示商品
   - 可配置：列数、是否显示价格
   - 数据来源：通用数据（商品表）
   - 使用场景：商品列表、推荐商品

6. **公告（notice）**
   - 功能：展示公告或提示信息
   - 可配置：背景色、文字色、图标
   - 使用场景：系统公告、活动通知

7. **标签页面（tabs）**
   - 功能：展示可切换的标签页内容
   - 使用场景：分类展示、内容切换

8. **内容列表（content-list）**
   - 功能：展示图文结合的内容列表
   - 数据来源：通用数据（文章表、知识库表）
   - 使用场景：文章列表、新闻列表

9. **搜索框（search）**
   - 功能：搜索功能
   - 使用场景：商品搜索、内容搜索

10. **注册登录（auth）**
    - 功能：用户注册登录
    - 使用场景：通用登录入口

##### AI特色组件
1. **AI分身（ai-avatar）**
   - 功能：AI智能体入口
   - 通过Webview跳转到AI卡牌训练平台
   - 使用场景：AI助手、智能客服

2. **AI任务（ai-task）**
   - 功能：AI任务管理
   - 四象限任务分类
   - 使用场景：任务管理、待办事项

3. **AI知识库（ai-knowledge）**
   - 功能：AI知识库入口
   - 使用场景：知识查询、智能问答

4. **组织圈子（circle）**
   - 功能：圈子管理
   - 使用场景：社群运营、用户互动

##### DIY组件（用户自定义）
- **功能描述**：用户可以创建自己的组件
- **创建流程**：
  1. 在组件库中点击"创建自定义组件"
  2. 输入组件名称和描述
  3. 通过AI辅助定义数据结构（键值对）
  4. AI自动生成组件代码
  5. 用户预览并确认
- **数据来源**：自定义数据（用户在明道云创建的表）
- **使用场景**：特殊业务需求、定制化功能

**验收标准**：
- 通用组件功能完整
- AI特色组件通过Webview正常运行
- DIY组件创建流程<5分钟

#### 2.1.4 数据绑定系统
**功能描述**：组件数据来源配置

**需求详情**：
- **数据来源类型**：
  - 通用数据：系统预置的表（商品、文章、知识库等）
  - 自定义数据：用户在明道云创建的表
- **排序规则**：
  - 通用数据：权重、发布时间正序/倒序、更新时间正序/倒序
  - 自定义数据：算法推荐（基于neirong表的权重计算）
- **过滤条件**：
  - 标签、分类、状态、时间范围等

**验收标准**：
- 数据绑定UI清晰易懂
- 排序规则动态生成
- 支持多种过滤条件

#### 2.1.5 定制化需求管理
**功能描述**：用户提交定制化需求，AI自动修改或人工介入

**需求详情**：
- **需求提交流程**：
  1. 用户在组件属性中备注需求
  2. 点击"提交需求"按钮
  3. 系统记录需求状态

- **需求状态**：
  1. **待处理**：需求刚提交，等待AI处理
  2. **AI处理中**：AI正在自动修改代码
  3. **待确认**：AI修改完成，等待用户确认
  4. **用户满意**：用户确认满意，需求完成
  5. **用户不满意**：用户不满意，重新提交需求
  6. **人工处理中**：平台技术工程师介入处理
  7. **已完成**：需求完成

- **AI自动修改流程**：
  1. AI分析需求
  2. AI修改组件代码
  3. AI生成预览
  4. 用户查看并反馈

- **人工介入流程**：
  1. 用户选择"人工介入"
  2. 平台技术工程师接收需求
  3. 工程师修改代码
  4. 用户确认满意

**验收标准**：
- 需求提交流程<1分钟
- AI响应时间<10分钟
- 人工介入响应时间<24小时

#### 2.1.6 小程序代码打包
**功能描述**：根据配置生成小程序代码并打包下载

**需求详情**：
- **打包流程**：
  1. 后端接收JSON配置
  2. 复制基础框架代码
  3. 根据配置生成页面代码
  4. 生成app.json（配置页面路径和tabBar）
  5. 下载图片到images目录
  6. 打包成ZIP文件
  7. 商家下载并导入微信开发者工具

- **打包内容**：
  - 基础框架代码（app.js、app.wxss、utils、components等）
  - 页面代码（index.js、index.wxml、index.wxss、index.json）
  - 图片资源（轮播图、图标等）
  - 配置文件（app.json、project.config.json等）

**验收标准**：
- 打包时间<30秒
- ZIP文件大小<10MB
- 代码可直接导入微信开发者工具

### 2.3 算法推荐系统

#### 2.3.1 neirong表设计
**功能描述**：存储内容权重数据

**需求详情**：
- **表结构**：
  - 内容ID：关联业务内容表（商品/文章/知识库/自定义表）
  - 评论基数：标准化后的评论数据
  - 收藏基数：标准化后的收藏数据
  - 主页转化基数：标准化后的主页转化数据
  - 标签基数：标准化后的标签数据
  - 完播基数：标准化后的完播数据
  - 评分基数：标准化后的评分数据
  - 加权基数：标准化后的加权数据
  - 成交基数：标准化后的成交数据
  - 发布时间：内容发布时间
  - 权重：综合计算后的权重值

- **权重计算公式**：
  ```
  权重 = 评论基数 × 评论因子
       + 收藏基数 × 收藏因子
       + 主页转化基数 × 主页因子
       + 标签基数 × 标签因子
       + 完播基数 × 完播因子
       + 评分基数 × 评分因子
       + 加权基数 × 加权因子
       + 成交基数 × 成交因子
       + 发布时间 × 发布因子
  ```

- **因子配置**：
  - 由商家在后台配置
  - 存储在neirong表或独立配置表

**验收标准**：
- 权重计算准确
- 因子配置灵活

#### 2.3.2 算法推荐流程
**功能描述**：基于neirong表的内容推荐

**需求详情**：
- **推荐流程**：
  1. 根据商家配置，从neirong表中按"权重"字段排序
  2. 得到一组内容ID列表
  3. 按排序结果依次到实际业务表（商品/文章/知识库/自定义表）中取数
  4. 按原顺序组装成列表
  5. 渲染到对应组件（商品列表、内容列表等）

- **非算法模式**：
  - 如果组件未启用算法推荐
  - 直接根据组件JSON中定义的数据来源表进行查询
  - 按商家定义的排序规则进行排序

**验收标准**：
- 推荐响应<2秒
- 推荐准确率>80%

## 三、数据逻辑

### 3.1 数据来源分类
所有组件的数据来源分为两类：

#### 3.1.1 通用数据
- **定义**：系统预置的业务表
- **类型**：
  - 商品表：商品信息、价格、库存等
  - 文章表：文章标题、内容、标签等
  - 知识库表：知识内容、分类等
- **特点**：
  - 表结构固定
  - 字段标准化
  - 适用于大多数商家

#### 3.1.2 自定义数据
- **定义**：商家在明道云自行创建的业务表
- **类型**：根据商家需求自定义
- **特点**：
  - 表结构灵活
  - 字段可定制
  - 适用于特殊业务需求

### 3.2 数据绑定规则
- **组件配置**：
  - `dataSourceType`：数据来源类型（common/custom）
  - `dataSourceKey`：数据来源标识（product/article/knowledge/custom）
  - `sorting`：排序规则
  - `filters`：过滤条件

- **数据加载**：
  - 通用数据：直接查询对应的业务表
  - 自定义数据：通过表别名和控件ID查询
  - 算法推荐：先查询neirong表，再查询业务表

### 3.3 数据存储
- **存储位置**：明道云
- **存储方式**：
  - 商家配置：以JSON格式存储
  - 页面配置：以JSON格式存储
  - 用户数据：存储在对应的工作表中
- **数据隔离**：
  - 每个商家的数据相互隔离
  - 通过merchantId区分

## 九、风险评估

### 9.1 技术风险
- **AI API成本**：可能超预期 → 设置调用限制
- **性能问题**：响应慢 → 优化和缓存
- **数据安全**：数据泄露 → 加强安全措施
- **AI完成度**：达不到预期 → 逐步优化，积累经验

### 9.2 市场风险
- **用户接受度**：用户不买账 → 快速迭代优化
- **竞争压力**：竞争对手 → 差异化定位
- **技术变化**：技术更新快 → 保持技术敏感度

### 9.3 商业风险
- **成本过高**：成本>收入 → 控制成本，提高效率
- **用户流失**：留存率低 → 提升用户体验
- **定制化需求**：需求过多 → 优化AI，提升完成度
