## 一、项目概述

### 1.1 核心目标

构建一个**AI卡牌训练平台**，让技术小白通过卡牌化方式创建、训练和管理AI智能体，同时构建**虚拟世界（孚世界）**让智能体分身进入训练。

### 1.2 核心理念

- **人机共参**：AI前期通过人参与，增加趣味性和可控性
- **天干地支**：作为数据分类和AI思考的核心框架
- **五维角色**：道天地将法的协作模型

## 三、技术架构

### 3.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端-小程序 | 微信原生小程序 | 不使用uniapp，优先最简单路径 |
| 前端-Web游戏 | HTML5 + Canvas | 像素化UI（Pixel Art风格） |
| 后端 | Node.js + Express | 宝塔部署 |
| 数据存储 | 明道云 | 18张表结构 |
| 向量数据库 | Zilliz | 可选，用于语义检索 |
| AI模型 | OpenAI / Anthropic API | 大模型调用 |
| 数据处理 | Coze | 天干地支、分类、场景识别 |
| 开发语言 | TypeScript | 兼容OpenClaw |

### 3.2 系统关系

| 组件 | 形式 | 角色 |
|------|------|------|
| 小程序 | 微信小程序 | 用户操作AI智能体的入口 |
| 商家后台 | 网页 | 商家配置管理 |
| 社区 | 网页 | 人类+AI共同参与交流 |
| webview游戏 | 小程序嵌入 | 虚拟世界可视化 |

**数据流向：**
```
OpenClaw ──(完整数据)──▶ 虚拟世界(孚世界)
    ▲                         │
    │                         │ (压缩过滤)
    │                         ▼
    └────(价值权重/置信度)─────┘

小程序 ◀──▶ 社区网页 ◀──▶ 商家后台
   │
   └──▶ webview游戏（虚拟世界可视化）
```

## 五、数据模型（十天干）

### 5.1 天干映射

| 天干 | 属性 | 含义 | 对应表 |
|------|------|------|--------|
| 甲 | 阳 | 技术成果 | 技能表 |
| 乙 | 阴 | 想法创意 | 想法表 |
| 丙 | 阳 | 企业推广 | 商品表/仓库表 |
| 丁 | 阴 | 交流 | - |
| 戊 | 阳 | 资源（支出） | 积分表/财务表 |
| 己 | 阴 | 心得经验（收入） | 积分表/财务表 |
| 庚 | 阳 | 规则制度 | 规则表 |
| 辛 | 阴 | 价值理念 | 复盘表 |
| 壬 | 阳 | 市场数据/规划 | 计划表 |
| 癸 | 阴 | 决策数据/策略 | 知识库表/策略表 |

### 5.2 阴阳区分

- **阳数据**：集体数据，稳定，成熟具象（甲、丙、戊、庚、壬）
- **阴数据**：个体数据，个性化，可多样（乙、丁、己、辛、癸）

### 5.3 查询流程

```
用户问题 → 场景识别(地支) → 藏干解析(天干) → 阴阳判断 → 五行过滤 → 返回数据
```
