# 天干地支系统定位说明

## 核心定位

**天干地支是系统的内核算法与后台逻辑，对用户是无感的。**

---

## 一、设计理念

天干地支是AI思考的技术架构，主要用于：

1. **训练AI**：作为智能体的思考机制
2. **数据分类**：后台对知识库、数据进行规律性分类
3. **决策支持**：根据阴阳五行判断发散或沿用，是否需要创意，是否考虑风险

---

## 二、用户无感原则

| 层面 | 说明 |
|------|------|
| **用户界面** | 用户看到的分类是「任务标签」「专题」等，不是天干地支 |
| **后台逻辑** | 系统内部用天干地支对数据进行打标、分类、关联 |
| **AI思考** | AI调用知识时，根据天干地支判断调用哪些数据，但用户不需要知道这个过程 |

---

## 三、前台展示 vs 后台逻辑

| 场景 | 前台（用户看到） | 后台（系统内部） |
|------|------------------|------------------|
| 社区分类 | 任务标签：求助、分享、讨论、资源 | 天干：甲、乙、丙、丁、戊、己、庚、辛、壬、癸 |
| 内容推荐 | 推荐算法 | 地支场景识别 + 藏干解析 |
| 智能体回答 | 直接展示答案 | 五行过滤 + 阴阳判断 |

---

## 四、分类对应关系（后台映射）

| 任务标签（前台） | 天干（后台） | 含义 |
|------------------|--------------|------|
| 技术 | 甲 | 专业技术、硬核知识 |
| 创意 | 乙 | 创新想法、个性表达 |
| 产品 | 丙 | 可变现的产品与服务 |
| 营销 | 丁 | 推广运营、营销策略 |
| 资源 | 戊 | 收入、资源、资产 |
| 求助 | 己 | 支出、需求、求助 |
| 制度 | 庚 | 规章制度、流程规范 |
| 理念 | 辛 | 价值观、理念文化 |
| 规划 | 壬 | 方向目标、战略规划 |
| 数据 | 癸 | 数据信息、资料整理 |

---

## 五、技术实现建议

1. **场景识别层**：根据场景锁定对话意图识别地支
2. **藏干解析层**：根据地支找到对应的天干组合
3. **阴阳判断层**：判断是发散（阴）还是沿用（阳）
4. **五行过滤层**：根据五行相生相克关系过滤数据

```
用户问题 → 场景识别（地支） → 藏干解析（天干组合） → 
阴阳判断（发散/沿用） → 五行过滤 → 返回数据
```
