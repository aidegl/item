# 元神表与分身表结构说明

## 概念

- **元神** = 主智体：一个主体身份，可以是真人或智能体。
- **分身** = 虚拟智体：一个元神下的多个虚拟身份，每个分身只归属一个元神。
- 元神可关联**用户表**中的一条记录：当元神是「真人」时，用「关联用户」指向该真人。

## 关系示意

```
用户表 (users)                    元神表 (main_mind)               分身表 (avatars)
─────────────                    ─────────────────                ───────────────
真人 / 智能体  ←── linked_user ──  主智体（真人/智能体）  ←── 1:N ──  虚拟智体
                                      │ 一个元神多个分身
                                      └── main_mind (分身 → 元神 多对一)
```

- 一个**元神**可以有多个**分身**（元神表通过双向关联会看到「分身」列表）。
- 一个**分身**只属于一个**元神**（分身表字段 `main_mind`）。
- 元神若为真人，在元神表填 `mind_type=真人` 并设置 `linked_user` 指向用户表中对应记录。

## 元神表字段 (main_mind)

| 字段名称 | 别名         | 类型     | 说明                         |
|----------|--------------|----------|------------------------------|
| 名称     | name         | 文本     | 主智体名称（标题）           |
| 类型     | mind_type    | 单选     | 真人 / 智能体                |
| 描述     | description  | 文本     | 描述                         |
| 使命     | mission      | 文本     | 使命                         |
| 关联用户 | linked_user  | 关联用户表 | 元神为真人时指向用户表一条 |
| 备注     | remarks      | 文本     | 备注                         |

## 分身表字段 (avatars)

| 字段名称 | 别名       | 类型     | 说明               |
|----------|------------|----------|--------------------|
| 名称     | name       | 文本     | 分身名称（标题）   |
| 元神     | main_mind  | 关联元神表 | 归属的元神（必填） |
| 描述     | description| 文本     | 描述               |
| 备注     | remarks    | 文本     | 备注               |

分身表与元神表为**双向关联**，元神表会自动出现「分身」关联字段，可查看该元神下的全部分身。

## 建表脚本

再次创建或在新环境执行：

```bash
node scripts/create-main-mind-tables.js
```

脚本会先建元神表，再建分身表并关联元神表；元神表中的「关联用户」指向项目内用户表 `users`（worksheetId 见脚本内 `USERS_WORKSHEET_ID`）。
