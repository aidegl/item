# 72地煞星介绍

## 概述

72地煞星是108将中的地煞部分（37-108号），每个地煞星都有其独特的职责和技能，并归属于不同的五行属性。根据五行属性，每个地煞星都有对应的元神（主智体），遵循"道天地将法"五维协作模型。

**地魁星（37号）是72地煞之首**，负责统筹协调所有地煞星的工作，是地煞星中的领导者。

## 五行分类与元神对应

根据五行分配规则：
- **37-44号（8个）**：🌬️ **木（将/风）** - 行动者
- **45-66号（22个）**：💧 **水（天）** - 收集者
- **67-88号（22个）**：🔥 **火（法）** - 包装者
- **89-108号（20个）**：🫔 **土（地/小粽）** - 运化者

每个地煞星的元神（主智体）就是其对应的五维角色。

## ⭐ 地魁星 - 72地煞之首

**地魁星（37号）**是72地煞星的首领，具有特殊的领导地位：

- **地位**：72地煞之首，负责统筹协调所有地煞星的工作
- **职责**：技术支持统筹、问题分级、资源调配
- **元神（主智体）**：木（将/风）- 行动者
- **特点**：作为地煞之首，地魁星既要具备行动者的快速执行能力，又要具备统筹全局的领导能力
- **作用**：在五维协作中，地魁星作为木系地煞的代表，负责协调其他地煞星的工作，确保整体协作顺畅

## 协作流程

在具体场景中，72地煞星按照其元神（主智体）的协作模式工作：

1. **木（将/风）地煞星（37-44号）**：快速执行、解决问题、探索新可能性
2. **水（天）地煞星（45-66号）**：收集数据、市场调研、分析反馈
3. **火（法）地煞星（67-88号）**：包装宣传、让产品漂亮受欢迎
4. **土（地/小粽）地煞星（89-108号）**：资源运化、财务报表、生长收藏管理

## 使用说明

每个地煞星都是独立的智能体分身，其元神（主智体）决定了其行为模式和协作方式。在实际应用中：

- **木系地煞星**：适合快速执行、技术攻关、问题解决等场景
- **水系地煞星**：适合数据收集、监控分析、调研评估等场景
- **火系地煞星**：适合产品包装、市场推广、用户运营等场景
- **土系地煞星**：适合资源管理、流程优化、质量保障等场景

通过五维协作模型，72地煞星可以协同工作，形成完整的智能体生态系统。
