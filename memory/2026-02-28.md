## 🎮 可视化游戏平台 - Webhook 方案

### 技术栈确认
- **前端**: 微信原生小程序 + Canvas (HTML5 + 像素化 UI)
- **后端**: Node.js v18+ + Express.js
- **数据库**: 明道云 (结构化) + Zilliz (向量)
- **部署**: 宝塔面板

### Webhook 优势
- ✅ 实时备份游戏数据到明道云
- ✅ 降低主流程延迟（异步处理）
- ✅ 解耦游戏逻辑和数据存储
- ✅ 容灾能力（主库故障可恢复）
- ✅ 完整事件日志（审计追踪）

### 推荐架构
```
用户操作 → API (实时) → 明道云主库
         → Webhook (备份) → 明道云备份库
```

### 关键游戏事件（触发 Webhook）
- 游戏开始/结束/升级/成就
- 卡牌创建/使用/更新
- 任务完成/状态变更
- 对话开始/消息/结束
- 天干地支分类结果
